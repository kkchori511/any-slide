# Codex 검토 반영 내역

검토 원문: `docs/codex결과_코드검토.md`. 번호는 그 문서의 문제 번호다.

## 고친 것

| 번호 | 내용 | 조치 |
| --- | --- | --- |
| 1 | 불러온 스티커 좌표로 HTML 속성 주입 | `sanitize()`가 허용 필드만 새 객체로 복사하고 숫자는 범위를 제한한다. 이미지는 `assets/` 안 파일만 허용한다. 악성 덱으로 확인했고 DOM에 남지 않는다. |
| 2 | 불러오기 실패가 기존 덱을 손상 | `Object.hasOwn`으로 형태를 판정하고, 후보 덱을 검증하고 렌더링해 본 뒤에만 교체한다. 빈 파일이나 `{}`는 오류로 처리한다. |
| 3 | 저장 실패와 손상을 숨김 | 저장 실패 시 화면 아래에 경고를 띄운다. 손상된 저장값은 `any-slide-deck-v1-broken`에 남기고 알린다. |
| 4 | 마지막 입력 후 200ms 이내 종료 시 저장 공백 | `pagehide`와 `visibilitychange`에서 즉시 저장한다. |
| 5 | 버튼의 Enter/Space가 슬라이드 이동으로 처리됨 | 버튼과 링크에서는 이동 단축키를 쓰지 않는다. 썸네일을 실제 버튼으로 바꿨다. |
| 6 | 스티커가 화면 밖으로 나가 회수 불가 | 이동은 절반 이상 슬라이드 안에 남도록, 크기는 40~1920px로 제한한다. |
| 7 | pointercancel과 캡처 해제 시 정리 없음 | up, cancel, lostpointercapture를 같은 마무리 함수로 처리한다. |
| 8 | 긴 글자가 다음 칸을 침범 | 글자 칸마다 최대 높이를 두고, 넘치면 글자 크기를 최대 55%까지 자동으로 줄인다. 본문과 보조 설명은 한 묶음으로 흘러가서 본문이 길면 보조 설명이 아래로 밀린다. 그래도 넘치면 편집 화면에 빨간 점선을 표시한다. |
| 9 | 둥실둥실 옵션 변경 뒤 선택이 해제됨 | 렌더링 전에 선택 번호를 보관했다가 복원한다. |
| 11 | 썸네일과 스티커 패널 접근성 | 썸네일 버튼에 이름과 현재 표시를 달고, 패널 버튼에 이름을 붙이고, 포커스 표시를 추가했다. |
| 12 | 편집 모드 버튼과 E 키가 동작하지 않음 | 해당 버튼과 E 키를 제거하고 발표 버튼 도움말에 Esc 종료를 적었다. |
| 13 | 한글 조합 중 Esc가 편집 필드를 blur | 조합 중(`isComposing`, keyCode 229)에는 앱 단축키를 처리하지 않는다. |
| 기타 | 첫/마지막 장에서 이동 키가 애니메이션을 재시작 | 같은 장이면 다시 그리지 않는다. 발표 중 키 입력도 HUD를 다시 보이게 한다. 최소 배율을 보장하고 사용하지 않는 `@keyframes noop`을 지웠다. |

## 아직 남은 것

- **10. 끝의 줄바꿈 1개 제거**: 의도한 마지막 줄바꿈이 저장 때 사라질 수 있다. 영향이 작아 두었다.
- **실제 브라우저 검증**: Codex는 브라우저를 실행하지 못해 Node 격리 실행으로 확인했다. 한국어 입력기 조합, 전체 화면 진입과 종료, Safari와 Firefox 동작은 직접 써 보며 확인해야 한다.
- **덱 규모**: 썸네일을 매번 다시 만들어서 슬라이드가 수십 장이 넘으면 부분 갱신이 필요하다.
