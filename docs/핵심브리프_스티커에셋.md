# 핵심 브리프: 스티커 에셋 (캐릭터·소품 이미지 생성용)

슬라이드에 들어가는 스티커 에셋(캐릭터, 소품, 장식)을 언제든 같은 스타일로 만들기 위한 브리프.
이미지 생성은 Codex의 이미지 생성 스킬로 하며, 생성 요청 때마다 이 문서의 **4번 프롬프트 블록**을 그대로 붙여 쓴다.
기준 이미지는 `내캐릭터_깨끗한아이보리메인_슬라이드6종_2026-10-20_v02/`의 `03_사용자원본이미지/`와 `04_배경과캐릭터소품/`이다.

## 1. 스타일 규칙 (모든 에셋에 공통)

- **재질**: 점토(클레이, 플라스티신) 질감의 3D 렌더. 손으로 빚은 듯한 둥근 형태, 표면에 미세한 손자국과 결이 있음.
- **형태**: 모서리 없이 통통하고 둥글게 단순화. 얇은 디테일은 굵게 과장함.
- **조명**: 부드러운 스튜디오 조명. 하이라이트는 은은하고, 강한 반사나 금속 광택은 쓰지 않음.
- **그림자**: 바닥 그림자와 드롭 섀도 없음. 소품 안쪽의 은은한 음영만 허용.
- **배경**: 투명(PNG RGBA) 또는 순백. 슬라이드 위에 올릴 수 있어야 하므로 배경색이나 종이 질감을 이미지에 넣지 않음.
- **외곽선**: 오려 낸 스티커처럼 객체 둘레에 얇은 흰색 다이컷 테두리를 둠. 검은 윤곽선은 넣지 않음.
- **글자와 숫자**: 넣지 않음. 단, 소품 자체의 상징은 허용함(π, Σ, 두뇌 칩의 "AI", 태블릿 앱 아이콘). 새 에셋에는 임의의 문구나 로고를 만들지 않음.
- **색감**: 선명하지만 채도가 과하지 않은 파스텔 톤 위주. 아래 팔레트를 기준으로 함.

## 2. 캐릭터 규칙

사용자 본인을 모델로 한 클레이 캐릭터. 아래를 바꾸지 않는다.

- **머리**: 짙은 갈색에 가까운 검정, 굵은 곱슬 웨이브. 숱이 많고 위로 솟은 모양.
- **얼굴**: 복숭아빛 피부, 둥근 얼굴. 눈은 웃는 반달(^ ^) 모양의 굵은 검은 선, 눈썹도 검은 선, 입은 넓게 웃는 곡선. 코는 작고 살구색 둥근 점.
- **볼**: 분홍색 동그란 볼터치를 양쪽에 둠.
- **의상**: 남색 바탕에 빨강, 흰색 줄이 섞인 체크 셔츠, 안에 흰 티.
- **기본 표정**: 미소. 다른 표정이 필요하면 눈, 입 선만 바꾸고 나머지는 유지함.
- **구도 변형**: 얼굴만(워터마크용), 상체와 양손(말풍선 설명용), 상체와 주변 소품 7종(표지·종료용).
- 새 포즈나 표정을 만들 때도 기준 이미지의 얼굴 비율과 머리 모양을 참고 이미지로 함께 전달함.

## 3. 소품 규칙

소품 7종은 한 세트로 보이도록 같은 클레이 스타일을 유지한다.

| 소품 | 설명 |
| --- | --- |
| 노트북 | 남색 몸체, 하늘색 화면, 회색 키보드 |
| 전구 | 노란색 전구, 갈색 회색 베이스, 노란 빛살 |
| 로봇 | 회백색 사각 얼굴, 남색 화면에 노란 눈과 주황색 미소, 분홍 귀, 주황 안테나 |
| AI 두뇌 | 무지개색 두뇌, 가운데 남색 칩에 "AI" |
| Σ | 파란색 굵은 기호 |
| π | 빨간색 굵은 기호 |
| 태블릿 | 검은 베젤, 다채로운 앱 아이콘, 펜 |

- 새 소품을 추가할 때는 같은 클레이 재질, 둥근 형태, 파스텔 톤을 지키고 주제와 어울리는 단순한 사물로 만듦.
- 소품은 객체 하나씩 투명 배경으로 만들고, 필요하면 배치(ㄱ자, 가로 일렬)는 슬라이드 쪽에서 함.

## 4. Codex 이미지 생성 프롬프트 블록

아래를 요청 맨 앞에 붙이고, 만들 대상만 `[대상]` 자리에 바꾼다.

```
Create a sticker-style asset in handmade claymorphism (plasticine / modeling clay) 3D style.
Subject: [대상, 예: a friendly clay robot holding a speech bubble]

Style rules:
- Soft rounded chunky shapes, no sharp edges, visible subtle fingerprint texture on the clay.
- Soft studio lighting, gentle highlights, no metallic or glossy reflections.
- NO drop shadow, NO floor shadow.
- Thin white die-cut sticker outline around the subject. No black outlines.
- Transparent background (PNG with alpha). Do not add any paper texture or background color.
- NO text, NO letters, NO numbers, NO logos, NO watermarks
  (only symbolic marks that are part of the object, e.g. pi, sigma).
- Pastel-leaning but vivid colors that match the reference palette.
- Output size 1254x1254, subject centered with comfortable margin.

Reference images: use the attached character and prop images for style and proportions.
```

캐릭터가 포함될 때는 아래를 추가한다.

```
Character must match the reference exactly: dark brown-black curly wavy hair, round peach face,
crescent-shaped smiling eyes and eyebrows drawn as thick black lines, wide smile, small salmon nose,
round pink cheeks, navy plaid shirt with red and white lines over a white tee.
```

## 5. 색상 기준

| 용도 | 색 |
| --- | --- |
| 슬라이드 배경 (메인) | 깨끗한 아이보리 `#F8F5EE` 전후, 미세한 종이 결 |
| 교체용 배경 | 세이지, 블루그레이 |
| 본문 글자 | 짙은 차콜 |
| 보조 글자 / 장번호 | 따뜻한 회갈색 |
| 소품 포인트 | 파랑(Σ, 노트북), 빨강(π), 노랑(전구), 분홍(로봇 귀, 볼터치), 무지개(두뇌) |

배경과 글자색은 기준 이미지에서 눈으로 본 값이므로, 앱을 만들 때 실제 PNG에서 색을 샘플링해 확정한다.

## 6. 파일 규칙

- 이름은 의도가 드러나게 짓는다. 예: `캐릭터_상체와양손_투명배경_말풍선설명용.png`.
- 새 에셋은 `04_배경과캐릭터소품/` 또는 앱의 에셋 폴더에 투명 PNG로 저장한다.
- 슬라이드에 올릴 때 크기는 앱이나 슬라이드 쪽에서 조절한다.

## 7. 품질 체크리스트

생성 결과를 받으면 아래를 확인하고, 하나라도 어긋나면 해당 항목만 짚어서 다시 요청한다.

- [ ] 점토 질감과 둥근 형태가 기준 이미지와 같은 세트로 보이는가
- [ ] 그림자(바닥, 드롭)가 없는가
- [ ] 투명 배경이고 가장자리에 흰 테두리가 깔끔한가
- [ ] 의도하지 않은 글자, 숫자, 로고가 없는가
- [ ] 캐릭터의 머리, 눈, 볼, 셔츠가 기준과 같은가
- [ ] 1254x1254이고 피사체가 잘리지 않았는가
