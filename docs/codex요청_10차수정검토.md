## 이번에 바뀐 것 (사용자가 승인한 10차 수정)

수업 자료(학습지)를 슬라이드로 쓰려고, 발표 화면에서 한 줄씩 보이고 빈칸 답을 하나씩 여는 기능.

1. **넘기기 설정** `settings.step`: `page`(장 단위, 기본) / `line`(한 줄씩, 수업 자료). [설정] 패널 맨 아래 `#selStep`. `sanitize`가 값을 거름.
2. **한 줄씩 넘기기** (`app.js` 「한 줄씩 넘기기」 구간, `setupSteps`·`showStep`·`advance`):
   - 발표 모드이고 `step === 'line'`일 때만(`stepMode()`). 렌더링에 `steps` 옵션을 넘겨 단위를 표시한다.
   - 본문·그림+설명·말풍선·비교 형태의 `body/sub/bubble/left/right` 칸은 줄마다 `<span class="ln" data-unit="ln">`(`markupToHTML(s, true)`).
   - 카드·단계는 상자(`.obj[data-unit=c1…/s1…]`), 단계 화살표 a1은 s2와 한 단계. 표는 머리 줄 빼고 행마다(`data-unit=r1…`).
   - 단계 순서는 문서 순서로 `[data-unit], .ans`를 훑어 만든다. 숨김은 `visibility:hidden`(`.stp-hid`)이라 자리와 글자 맞춤이 그대로.
   - 다음 키·클릭 → 다음 단계, 다 나오면 다음 장. 이전 → 마지막 단계를 숨김, 없으면 앞 장을 모두 보인 채로(`go(…, 'end')`).
3. **빈칸 표기** `[[답]]` (`deck-spec.js` `parseMarkup`/`runsToMarkup`, 서식 조각의 `a`):
   - `<span class="ans">`로 그림. 보통은 빨간 글자, 편집 화면은 옅은 빨간 바탕. 한 줄씩 넘기기의 발표 화면에서만 `.hid`(글자 투명 + 회색 밑줄)로 시작.
   - 편집 도구 [빈칸](`applyFormat(el, 'a')`), DOM → 표기 왕복(`domItems`, `itemsToRuns`).
   - `[`, `]`는 표기 문자(SPECIAL)에 넣어 조각 경계·연속일 때 `\`로 감쌈.
4. 문서: `app/README.md`, 스킬 문서 두 벌(같은 내용, 「수업 자료」 절: 학습지·hwpx 메모 정답·수식), AGENTS.md.

Claude가 확인한 것(헤드리스 Chrome): 본문(제목 빈칸 1, 줄 4, 빈칸 3)·카드·단계(화살표 묶음)·표·비교·큰 한 문장의 단계 목록과 순서, 앞으로 9번·뒤로 3번 상태, 앞 장으로 돌아가면 모두 보임, 장 단위면 단계 0개·바로 다음 장, 편집 화면에서 답이 빨갛게 보이고 숨김 없음, 표기 왕복(`=` 이스케이프 차이만), [빈칸] 켜고 끄기, 설정 메뉴 값, 표기 왕복 단위 시험 8개, 기본 덱 13장 캡처가 main과 바이트 단위로 같음.

## 지시 사항 (검토만 한다)

- **소스 파일을 고치지 않는다.** 의견과 수정 제안만 보고서에 적는다.
- **Chrome은 실행하지 않는다.** 코드 읽기와 Node 격리 실행으로만 확인한다.
- **텔레그램 등 밖으로 아무것도 보내지 않는다.**
- `decks/`의 파일과 바탕화면은 읽기만 한다.

중점적으로 볼 것:
- 표기: `[[`/`]]`와 다른 표기(**, {{색:}}, \ 이스케이프)가 섞일 때 파싱·왕복, 예전 덱의 `[`·`]` 글자가 바뀌는지, `stripMarkup`을 쓰는 곳(자동 정렬, check-deck)
- 단계: 단계 순서(제목·표 머리 줄·스티커 안의 빈칸), 빈 줄, 숨긴 개체(layout hidden), 그림 칸, 장 전환 중 연속 입력, 발표 시작·끝, [설정] 변경, 다시 그리기(renderStage가 단계 상태를 지우는 경우)
- 편집 화면·썸네일·인쇄에 단계 표시가 새지 않는지, 기본 덱이 그대로인지
- 숨김 표시: 색 표기·형광펜·밑줄이 있는 빈칸, 접근성(화면 읽기), 발표 중 클릭
- README·스킬 문서와 코드가 맞는지
