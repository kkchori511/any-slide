# Any Slide 앱

발표용 슬라이드 웹 앱. 빌드 없이 `Any-Slide.html`을 브라우저(Chrome·Edge 권장)로 열면 된다. 로컬에서 쓰는 앱이라 웹 서버나 인터넷이 필요 없다.

```sh
open app/Any-Slide.html
```

발표할 때는 덱마다 만든 **발표 폴더**(예: `~/Desktop/2026-10-27_API_이용_앱_만들기_v1/`)의 `Any-Slide.html`을 연다. 폴더에 덱이 함께 들어 있어서 바로 그 덱이 열리고, 폴더째(또는 폴더와 같은 이름의 zip으로) 다른 컴퓨터·윈도우로 옮겨도 그대로 쓸 수 있다.

발표 폴더에서 고친 내용은 그 컴퓨터의 브라우저에 저장된다. 고친 덱을 다른 컴퓨터로 옮기려면 먼저 **[폴더에 저장]**(크롬·엣지)으로 폴더 안의 덱에 쓰고 폴더를 복사한다. 앱은 폴더의 덱과 브라우저에 저장된 덱 중 **더 최근에 고친 쪽**을 열고, 바뀐 쪽은 브라우저에 백업해 둔다. 사파리·파이어폭스에서는 [저장]으로 내려받아 옮긴 뒤 [불러오기]로 연다. 폴더의 덱을 읽지 못하면 경고와 함께 예제 덱을 열고, [불러오기]로 덱을 열 때까지 저장하지 않는다.

## 사용법

- **편집**: 슬라이드의 글자를 클릭해서 바로 수정한다. 변경은 브라우저에 자동 저장된다. 글이 적으면 칸에 맞게 커지고, 많으면 작아진다.
- **개체**: 형태의 그림, 글상자, 카드, 말풍선, 표, 그림 칸은 모두 개체다.
  - 그림은 끌고, 글상자는 테두리를 끌어 옮긴다. 모서리·변의 점으로 크기, 위쪽 둥근 손잡이로 회전(Shift: 15도씩)한다.
  - 끄는 동안 다른 개체와 슬라이드 가운데·여백선에 가까워지면 빨간 보조선과 함께 달라붙는다. ⌥(Alt)를 누른 채 끌면 맞춤 없이 움직인다.
  - 개체를 고르고 화살표로 10px(Shift: 50px)씩 옮기고 `Delete`로 삭제한다. 도구 줄의 [원래 위치로], [숨긴 개체 보이기], [원래 배치로]로 되돌린다.
  - 그림 칸은 두 번 누르면 그림을 고른다.
  - 덱 전용 그림(노션 그림 등, 덱의 `media/<파일>`)은 발표 폴더의 `media/` 안에 있어야 보인다. 그림 패널에는 나오지 않으므로, 그림 칸에서 다른 그림으로 바꾸거나 빼면 앱에서는 다시 넣을 수 없다(덱 JSON의 `img`를 고친다).
- **정렬**: 표 머리 줄과 상자 제목은 가운데다. 나란히 놓인 상자와 표의 각 열은 정렬이 하나로 통일된다(하나라도 길면 모두 왼쪽, 모두 짧으면 모두 가운데). 도구 줄로 바꾸면 그 상자는 그 값이 우선이다.
- **도구 줄**: 위쪽 두 번째 줄은 고른 것에 따라 바뀐다.
  - 글자를 고르면: 굵게(⌘B), 밑줄(⌘U), 형광펜, 글자 색(빨강·파랑·초록·주황·회색·검정과 무지개 동그라미의 [다른 색]: 스펙트럼에서 고르고 창을 닫으면 칠해진다), 칸 전체의 크기·정렬·줄 간격. 글자를 드래그해 고르면 그 부분만, 고르지 않으면 칸 전체에 적용된다.
  - 스티커를 고르면: 회전 0°, 뒤집기, 앞으로·뒤로, 복제, 둥실둥실, 삭제.
  - 아무것도 고르지 않으면: 이 장의 옵션(카드·단계 개수, 표 줄·칸, 그림 칸).
- **슬라이드 관리**: 위쪽 도구 모음에서 추가, 형태 변경, 복제, 순서 이동, 삭제를 한다. 왼쪽 썸네일을 눌러 이동한다. 형태는 13가지다(표지, 본문, 말풍선, 2단 비교, 카드, 단계, 큰 한 문장, 코드·주소, 표, 그림+설명, 챕터 A·B, 종료).
- **스티커**: [스티커]에서 고르면 슬라이드 가운데에 놓인다. [기본] 탭에 기본 8개, [추가] 탭에 덱을 만들며 새로 생성한 그림이 있다. 끌어서 옮기고, 네 모서리 점으로 크기, 위쪽 둥근 손잡이로 회전한다(Shift: 15도씩). 화살표 키로 10px(Shift: 50px)씩 옮기고 `Delete`로 지운다.
- **설정**: [설정]에서 배경, 글꼴, 장 전환(없음·페이드·밀기·확대·위로 올라오기)과 속도, 이 장만 다른 전환, 글자 등장(날아오기·페이드만·없음), 그림 등장, 둥실둥실을 정한다.
- **발표**: [▶ 발표] 또는 `F`. 전체 화면으로 열린다. `←` `→` `Space` 또는 화면 클릭으로 넘기고 `Esc`로 끝낸다.
- **저장/불러오기**: [저장]으로 덱을 JSON 파일로 내려받고 [불러오기]로 다시 연다. 잘못된 파일이면 현재 덱을 그대로 둔다.
- **인쇄 (PDF)**: [인쇄]를 누르면 모든 장이 등장 효과 없이 1920×1080 쪽으로 담긴 인쇄 창이 뜬다. PDF는 대상을 **PDF로 저장**으로 고르고(크롬은 다음부터 기억한다), 일부 장만 뽑으려면 인쇄 창의 **페이지**에서 고른다. 쪽 크기, 여백 없음, 배경 인쇄는 앱이 정해 두었다. 파일 이름 기본값은 발표 폴더 이름(저장소 앱에서는 `Any-Slide`)이다. 그림·글꼴은 3초까지 기다리고, 그 안에 다 불러오지 못하면 아래쪽에 경고를 띄운 뒤 불러온 만큼으로 인쇄한다. 준비하는 동안은 [인쇄]가 잠긴다. **크롬으로 인쇄한다.** 크롬에서는 한 장이 한 쪽에 그대로 나오지만 사파리에서는 쪽이 잘린다. 엣지 등 다른 크로미움 계열 브라우저도 같을 것으로 보지만 확인하지 않았고, 파이어폭스도 확인하지 않았다.
- **폴더에 저장**(발표 폴더에서만 보임): 고친 덱을 폴더 안의 `deck-data.js`와 덱 JSON에 직접 쓴다. 처음 한 번 그 발표 폴더를 고르면 창을 닫을 때까지 다시 묻지 않는다.
- **정보**: 메뉴 줄 맨 오른쪽 [Any-Slide]를 누르면 버전과 제작 정보가 보인다.
- **글꼴**: 기본은 페이퍼로지(Paperlogy)이고 `fonts/`에 들어 있어서 인터넷 없이도 보인다. 다른 글꼴을 쓰려면 설정의 글꼴 칸에 컴퓨터에 설치된 글꼴 이름을 적는다. 페이퍼로지는 SIL Open Font License 1.1이며 라이선스는 `fonts/OFL-Paperlogy.txt`에 있다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `Any-Slide.html` | 도구 모음(두 줄), 썸네일, 무대, 스티커·설정 패널 |
| `style.css` | 화면 스타일, 등장 애니메이션, 장 전환 |
| `deck-spec.js` | 슬라이드 형태(`TYPES`), 허용 스티커(`STICKERS`), 글자 색, 덱 설정, 서식 표기, 기본 덱, 덱 검증 |
| `app.js` | 렌더링, 글자 서식 편집, 자동 맞춤, 스티커 조작, 장 전환, 발표 모드, 저장 |
| `assets/` | 배경, 캐릭터, 소품 PNG |
| `assets/generated/` | Codex 이미지 생성으로 만든 스티커 |

새 슬라이드 형태를 추가하려면 `deck-spec.js`의 `TYPES`에 항목을 더한다. 좌표는 1920x1080 기준이다.
새 스티커를 추가하려면 `assets/generated/`에 투명 PNG를 넣고 `deck-spec.js`의 `STICKERS` 목록에 경로를 적는다. 스타일 규칙은 `docs/핵심브리프_스티커에셋.md`를 따른다.

## 개발용 URL 해시

- `Any-Slide.html#s=3` : 3번 슬라이드로 연다.
- `Any-Slide.html#s=3&view` : 전체 화면 요청 없이 발표 화면으로 연다. 화면 캡처 확인에 쓴다.

## 덱 파일로 내용 넣기

발표 내용은 `decks/`에 덱 JSON으로 만들고 [불러오기]로 연다. Claude나 Codex에게 "이 내용으로 슬라이드 만들어 줘"라고 하면 `slide-deck` 스킬(`.claude/skills/slide-deck/`, `.codex/skills/slide-deck/`)에 따라 덱 파일을 만든다. 예시는 `decks/예시_앱사용안내.json`.

- 검사: `node .claude/skills/slide-deck/scripts/check-deck.mjs decks/<파일>.json`
- 미리 보기(PNG): `node .claude/skills/slide-deck/scripts/preview-deck.mjs decks/<파일>.json <출력폴더>`
- 발표 폴더 만들기: `node .claude/skills/slide-deck/scripts/pack-deck.mjs decks/<파일>.json --title "<제목>" [--dest ~/Desktop] [--version N] [--zip]`
- 텔레그램 다다비서봇으로 보내기(허락받은 뒤): `node .claude/skills/slide-deck/scripts/send-telegram.mjs <파일>`

덱 규칙(슬라이드 형태, 허용 스티커, 검증)의 원본은 `app/deck-spec.js`다.
