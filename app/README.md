# Any Slide 앱

발표용 슬라이드 웹 앱. 빌드 없이 `index.html`을 브라우저(Chrome 권장)로 열면 된다.

```sh
open app/index.html
```

## 사용법

- **편집**: 슬라이드의 글자를 클릭해서 바로 수정한다. 변경은 브라우저에 자동 저장된다.
- **슬라이드 관리**: 위쪽 도구 모음에서 추가, 형태 변경, 복제, 순서 이동, 삭제를 한다. 왼쪽 썸네일을 눌러 이동한다.
- **스티커**: [스티커] 버튼에서 고르면 슬라이드 가운데에 놓인다. 끌어서 이동하고, 선택했을 때 보이는 모서리 점으로 크기를 바꾼다. `Delete`로 삭제한다.
- **발표**: [▶ 발표] 또는 `F`. 전체 화면으로 열린다. `←` `→` `Space` 또는 화면 클릭으로 넘기고 `Esc`로 끝낸다.
- **저장/불러오기**: [저장]으로 덱을 JSON 파일로 내려받고 [불러오기]로 다시 연다. 잘못된 파일이면 현재 덱을 그대로 둔다.
- **글꼴**: 도구 모음의 글꼴 이름 칸에 컴퓨터에 설치된 글꼴 이름을 적는다. 비워 두면 시스템 글꼴을 쓴다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 도구 모음, 썸네일, 무대, 스티커 패널 |
| `style.css` | 화면 스타일과 애니메이션 |
| `app.js` | 슬라이드 6종의 레이아웃 정의(`TYPES`), 렌더링, 편집, 스티커, 발표 모드, 저장 |
| `assets/` | 배경, 캐릭터, 소품 PNG |
| `assets/generated/` | Codex 이미지 생성으로 만든 스티커 |

새 슬라이드 형태를 추가하려면 `app.js`의 `TYPES`에 항목을 더한다. 좌표는 1920x1080 기준이다.
새 스티커를 추가하려면 `assets/generated/`에 투명 PNG를 넣고 `app.js`의 `STICKERS` 목록에 경로를 적는다. 스타일 규칙은 `docs/핵심브리프_스티커에셋.md`를 따른다.

## 개발용 URL 해시

- `index.html#s=3` : 3번 슬라이드로 연다.
- `index.html#s=3&view` : 전체 화면 요청 없이 발표 화면으로 연다. 화면 캡처 확인에 쓴다.
